Правила работы с Git
  • Ветки. main защищена, работа идёт в feature/logic (Андрей), feature/ui (Соня) и feature/data (Баженов). Перед слиянием — git pull --rebase origin main, затем Pull Request. В main вливают через --no-ff.
  • Ревью по кругу. Андрей проверяет Баженова, Баженов проверяет Соню, Соня проверяет Андрея.
  • Сообщения. Conventional Commits на русском: feat, fix, refactor, docs, test, chore.
  • Сборка. Каждый коммит должен собираться командой dotnet build.
  • Теги. v0.1-mvp (8 ноября), v0.5 (14 ноября), v1.0 (19 ноября).
  • Порядок в течение дня. Если у двух участников зависимые коммиты в один день, сначала вливается коммит автора зависимости. Такие места отмечены в карточках.
  • Даты плановые. Коммитьте по мере реальной работы. Если день сдвинулся, сдвигайте и остальные, но сохраняйте порядок зависимостей.
